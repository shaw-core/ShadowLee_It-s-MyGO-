## 优先级 P0：已明确报告的 Bug（必须实修）
1. **企鹅替换熊猫未生效**：在悠亚/企鹅模式检查所有 2D/3D 场景、checkpoint、动画、实例化对象、存档读档、切换/退出、隐藏区域；核实真正加载企鹅 mesh/material/texture，而非仅改变名称、图标或 UI。确保默认 Kimo 熊熊猫不受影响。截图/自动化验证切换前、切换后、切回三种状态。
2. **真结局两人房间的特殊 CG 闪烁**：检查 TrueEnding.tsx 的资源加载、状态更新、动画帧、depth fighting/z-fighting、重复渲染、贴图透明混合、灯光、canvas/CSS 动画。定位原因，修复后测试持续停留、快速进入退出、不同刷新率。不得简单隐藏 CG。
3. **墙上占位照片**：枚举所有墙上照片和占位素材，替换为仓库已有真实且许可明确的游戏图片/官方允许使用的素材。缺失时生成**待提供素材清单**并保留精致非误导性相框，不可虚构真实人物照片，不可用随机网图凑数。与真结局引用的素材保持一致。
4. **2D 班电脑桌缺少桌面**：定位 2D 班场景（注意可能在 3D 模型中），修正 mesh 几何、法线、材质、碰撞、遮挡及 LOD；检查视角变化下是否依然可见、能否正确承载物品。

## 优先级 P0.5：新增关卡与房间细节修复（必须实修）
5. **某一关地刺漏画、隐形伤害块**：逐关扫描 2D 与 3D 地刺的绘制、tilemap、collision/hazard map、物理碰撞盒与实例化坐标。用户反馈：一段地刺区域中有一块**外观完全是普通地面颜色、没有可见地刺**，但玩家碰到仍判定死亡。找到具体关卡和坐标并记录；核对究竟是漏渲染地刺还是多设了致死碰撞。修复原则：**可见危险与实际致死判定必须一致**。如果该格设计为地刺，补足与相邻地刺一致的可见形状/动画；如果本来是安全地面，则移除错误伤害判定。不能只在说明中提醒玩家、不能简单扩大伤害范围、不能破坏其他地刺关卡。添加地刺可视化与碰撞覆盖对照调试图，实测安全地面可站立、每块可见地刺致死、边界没有透明致死区域。
6. **真结局二人的房间：床上枕头模型**：定位房间的床和枕头 mesh，修正枕头当前不自然的形状、比例、位置、朝向、材质和与床铺的贴合；做出具有柔软体积、合理厚度及轻微布料褶皱的低多边形枕头，而不是漂浮、穿模或方砖。检查镜头各角度和灯光下的表现。
7. **真结局二人的房间：床上熊猫模型**：这是房间中的**熊猫玩偶/摆件模型**，不要和第二章存档点熊猫、Kimo 熊本体、悠亚模式企鹅替换混为一谈。根据房间语境调整轮廓、四肢、头身比例、眼睛、耳朵、颜色、摆放姿态与接触阴影，使其像可爱的实体玩偶而非临时几何拼装。保留世界观和角色辨识度；检查枕头、被褥、床头板的穿插关系。房间熊猫默认应仍是熊猫，不能因为企鹅模式修复而被无条件替换。
8. **第一章弹簧床：整张床均应弹跳**：定位第一章所有弹簧床/弹跳床的平台几何、渲染和碰撞组件。目前只有床的局部呈现或触发弹簧效果，要求**整张床的可站立床面都是弹簧床面**：视觉上整个床面均有统一且连贯的弹性结构或反馈，物理上从床面左、中、右各处落下均触发同一套弹跳机制。床架/床腿等非床面部分不应误触发；保留弹跳力度、方向和通关可达性，检查边缘、连续跳跃、落地判定、动画与音效同步。不要仅重复绘制单个弹簧图标而忽略物理区域。

新增四项与前述 P0 同等需要明确验收；在 `AUDIT.md` 和 `QA_CHECKLIST.md` 中逐项列出场景/关卡坐标、原因、修复代码、截图及运行验证。序号不代表可以跳过原 P1/P2 工作。
