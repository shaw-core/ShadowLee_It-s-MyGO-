# 角色互动关系与导演手册（供 Claude 理解，非台词素材）

## 李豆沙
最常主动靠近、撒娇、要求拥抱、求关注；有小聪明，偶尔嘴硬、被逗到说话打结，也会突然勇敢。她不是永远害羞、等待室友姐拯救的乙女游戏女主角。撒娇常带具体动作：拽衣袖、扑过去、凑近、找借口让人陪。面对世界异常，先用日常语言描述看到的现象，再逐渐害怕、认真。

## 室友姐
日常会笑着逗人、偶尔吃醋或委屈，也会温柔照顾、主动回应，能被李豆沙反过来逗到。她不是霸总、训导者、全知旁白，也不应一直用“笨蛋”结尾。感情通过记得喜好、带糖、等人、伸手、替人留灯表达。偶尔有关键短句即可，不要连续抛出宏大哲理。

## Kimo 熊
自称“Kimo 熊”；叫李豆沙“小李小李”“豆沙”“李豆”“姐姐”“妈妈妈妈”等；李豆沙称“Kimo 熊”。小动物般亲近、可爱、会害怕、想被摸头、想见人，但它的温柔和行动有分量。它能设置部分 checkpoint，不能任意修改世界规则；另一部分熊猫涉及 TV-head/其他时间线伏笔，不要写成全部由 Kimo 熊设置。揭露风险时仍应保留“接不到小李了”这样符合其口吻的表达。它不是黑手。

## 三人关系的叙事弧
第一章：先让玩家喜欢李豆沙与室友姐平凡的小日子；奇怪的黑白、七点整、电视头、原稿、重复日历、蓝弹幕悄悄侵入。第二章：她们在多边形世界里互相依靠；玩家通过反复跌落体会 checkpoint 熊猫的保护。终关：Kimo 熊承认它有边界，愿意守护却无法代替两人冒险；室友姐并非“新的存档系统”，而是愿意和豆沙一起面对不可重来的选择。隐藏档案揭示曾经失败的时间线，前面必须有公平、可回看的证据。

## 现实互动素材带来的写作规律
- 真实相处中，两个人都可能吃醋、委屈、逗弄、解释不清；不是固定“强势者+弱势者”。
- “那你为什么这种语气”“我哪副表情”“我没有……不是不是”这样的反复与打岔可以用于表现熟悉关系，但不能机械复制切片原句。
- 互动的重点是“一个小动作引出另一个人的回应”，而不是把每句话写成情话。
- 不要把所有直播梗当作剧情事实；游戏是原创同人世界。

## 演出建议
同一句话可以通过表情、停顿、贴近、收回手、场景声音表达多层情绪；文本优先简洁。异常出现时避免大段解释。小熊不需要每句都重复口头禅，但重要剧情时要保持其声音可辨认。
