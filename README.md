# ShadowLee: It's MyGO!

> 一款以虚拟主播 **李豆沙** 及其相关角色设定为基础制作的非官方粉丝同人游戏。
> 在不同世界与叙事图层之间穿行，收集散落的信息，抵达故事表面之下的真相。

## 游戏简介

《ShadowLee: It's MyGO!》是一款融合了：

* 2D 平台跳跃
* 3D 场景探索
* 视觉小说式剧情
* 多图层切换
* 文档收集与密码解谜
* 隐藏路线与特殊结局

的浏览器同人游戏。

玩家将控制李豆沙的不同形象，在看似彼此独立的关卡和剧情片段中寻找线索。

部分信息不会被直接说明。关卡中的草稿页、碎片、系统档案、角色对话以及异常演出，可能共同指向另一个版本的故事。

## 游戏内容

### 第一章 · 漫画的世界（2D）

在现实图层与漫画图层之间切换。墨水会从李豆沙脚下扩散开，整个画面变成黑白网点。

两个图层具有不同的平台、障碍和通行路线。玩家需要利用图层差异完成平台跳跃，并收集散落在关卡中的百合页和碎片。七话关卡各有自己的场景：房间、黄昏的街、深夜的公寓、快递站、回家的路、弹幕、天台。

### 第二章 · 多边形的世界（3D）

进入三维的浮空岛屿，选择不同的李豆沙形象进行探索。室友姐会一直跟在身后。

不同角色外观不仅是视觉差异。某些角色可能拥有与世界系统不同的关系，并能够触发普通角色无法触发的内容。

### 剧情与手账

完成关卡、取得特定收集品后，可以解锁角色对话、漫画分镜过场和关卡中的小剧场。

《豆沙的手账》会记下她见过的人和事，已经读过的剧情也可以在手账的「回忆」里重新播放。

### 隐藏系统

游戏中存在需要额外条件才能访问的系统内容，包括：

* 散落的草稿页
* 加密档案
* 密码终端
* 特殊 CG
* 隐藏角色外观
* 特殊终端演出
* 隐藏结局

部分谜题需要结合多个关卡中的信息才能理解。

## 基本操作

### 第一章（2D）

| 操作        | 按键                  |
| --------- | ------------------- |
| 向左移动      | `A` / `←`           |
| 向右移动      | `D` / `→`           |
| 跳跃        | `W` / `↑` / `Space` |
| 切换现实与漫画图层 | `Q`                 |
| 查看 / 说话   | `E`                 |
| 暂停        | `Esc`               |

### 第二章（3D）

| 操作        | 按键                  |
| --------- | ------------------- |
| 移动        | `WASD` / 方向键        |
| 跳跃        | `Space`             |
| 切换现实与线框图层 | `Q`                 |
| 和室友姐说话（隔着几步也行） | `R` |
| 摸摸熊猫 | `F` |
| 外观技能（电视头小豆：缓存锚点） | `E`   |
| 转动视角 / 缩放  | 拖动鼠标 / 滚轮          |
| 暂停        | `Esc`               |

### 对话

| 操作        | 按键                  |
| --------- | ------------------- |
| 继续        | 点击 / `Space` / `Enter` |
| 快进已读      | 按住 `Ctrl`           |
| 自动播放      | `A`                 |
| 回看        | `L`                 |
| 选择        | `1` ~ `3`           |

### 随时可用

| 操作        | 按键                  |
| --------- | ------------------- |
| 掏出随身听     | `M`（或主菜单 / 暂停菜单里的「随身听」） |

每个场景都有自己的原创配乐；想听那几首 8bit 歌，就掏出随身听，场景配乐会自动安静下来。

音量、画质（流畅 / 均衡 / 精致）、减少晃动、对话速度等可以在「设置」里调整。

## 推荐游玩方式

为了获得较完整的体验，推荐：

1. 先正常完成第一章与第二章。
2. 尽量收集每个关卡中的纸页、碎片和薄荷糖。
3. 翻翻手账里新写下的内容。
4. 留意文档里的日期、编号、措辞和互相矛盾的信息。
5. 尝试使用不同角色重新进入部分内容。
6. 在达成隐藏路线后，再次观察标题画面。

本作的一些关键叙事并不发生在传统剧情对话中，而是隐藏在界面变化、系统反馈和游戏规则本身之中。

## 当前版本特色

### v0.14.0（大更新）

* 两章全部重做：第一章换成手绘像素美术（七个场景、角色动画、立绘表情），第二章换成精致低模 + 柔光（浮空小岛、云海、天空、泛光后期）。

* 第二章关卡之间加入 3D 分镜漫画，背景加入整块漂浮的街区。
* 真结局变成「她们的房间」：通关第一章即可进入（2D），通关第二章后可以切换到 3D。
